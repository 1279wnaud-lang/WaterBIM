# 관·이형관 규격 사전 — 1차 정리

WaterBIM의 `pipe-catalog.json`은 원문 치수와 출처를 보존하는 데이터입니다. Revit 룩업 CSV나 패밀리 타입 카탈로그 파일 자체는 아닙니다.

## 수록 범위

총 382개: 닥타일 상수 2·3종 직관부 50개, 플랜지 소켓관 75개, 플랜지관 25개, 이음관 50개, 강관 직관 42개, F12·F15 90°·45° 곡관 140개.

T관·이경관·닥타일 곡관·특수이형관·F20 및 STWW400 B는 아직 구조화하지 않았습니다. 직관 소켓·라이닝과 길이별 관 총중량도 미수록입니다. 미수록 규격을 추정하거나 보간하지 않습니다.

## 데이터 계약

- `schemaVersion`: 현재 1.
- `records[].id`: 규격별 고유 식별자. 화면 순서나 표 행 번호를 ID로 사용하지 않습니다.
- `material`, `part`: 관종과 부품.
- `keys`: 호칭경(mm), 구분, 접합방식, 해당 시 각도(deg). 호칭경과 외경은 다른 필드입니다.
- `dimensions`: 수치만 저장. 각 키의 단위와 원문 기호는 `fields`에 정의합니다. kg와 kg/m를 구분합니다.
- `source`: 문서 ID, 실제 PDF 페이지(1부터 시작), 책 페이지, 표·도식 이름, 페이지 이미지.
- `sources`: 문서명, 판본, 로컬 원문 경로, 파일 SHA-256. 원문 판본 식별용입니다.
- `validation`: 원문 대조 상태와 수치 불일치 기록. `currentStandardVerified`는 모두 false입니다.
- `notes`: 당시 공급범위, 중량 포함범위 등 원문 주석과 수록 제한.
- 원문 공란은 속성을 생략합니다. 0과 null로 치환하지 않습니다. 타이튼 플랜지 소켓관 DN2200/2400/2600의 무게가 해당합니다.

원문 내경 불일치 4개는 자동으로 고치지 않았습니다. 강관 45° 곡관 F12·F15 각각의 DN1500/2500입니다. `needs-review` 행은 향후 패밀리 적용 시 자동 확정 대상에서 제외해야 합니다.

## Pruden in Revit 연계

내보낸 JSON에는 필드 정의, 원문 판본, 검토 상태가 함께 포함됩니다. 후속 애드인은 이 데이터를 읽어 필드를 사용자 패밀리 매개변수에 매핑하고 단위를 변환해야 합니다. 조회 키는 관종/부품/구분/접합방식별로 분리한 후 선택해야 합니다. 형상 도식의 `L`, `l1`, `R` 등을 의미가 다른 매개변수에 자동 연결하지 않습니다. 현재 규격만으로 완성된 RFA를 생성한다고 가정하지 않습니다.

## 재생성·검증

- 원문 데이터 재추출: `python scripts/build-pipe-catalog.py` (pdfplumber, pypdfium2 및 원문 G: 드라이브 필요)
- 일반 앱 빌드: `node scripts/build-html.js`, `node scripts/build-artifact.js` (PDF 드라이브 불필요)
- 데이터·검색·출처·단위·문법 검사: `node scripts/test-pipe-catalog.js`
- 원문 스냅샷: `pipe-sources/*.webp`. 빌드 시 HTML 내부에 포함하므로 단일 HTML에서도 볼 수 있습니다.

실제 브라우저 렌더링 검사는 로컬 URL 접근 정책 제한으로 미완료입니다. JSDOM 검증은 DOM·이벤트 검사이며 화면 배치나 실제 다운로드 허용 여부를 보증하지 않습니다.
