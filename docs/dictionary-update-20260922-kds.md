## 대상과 방법

같은 날 `02_기관별_지침`을 대조한 작업(`docs/dictionary-update-20260922.md`)에 이어, 그 작업이 보지 않은 국가건설기준 316개 파일(KDS·KCS 57·61, KWCS)을 대상으로 했다.

- 각 기준의 **'용어의 정의' 조항(253개)** 에 정의된 용어만 뽑았다. 본문에 한 번 나온 단어는 넣지 않았다.
- 원문은 설계기준 검색 색인과 같은 방법(rhwp 추출 → 화면 줄바꿈을 문단으로 복원 → 머리글·쪽 번호 제거)으로 읽었다.
- 정의 형식 두 가지를 읽었다: `∙ 용어 : 정의`(KWCS·KCS), `(1) "용어"란 … 을 말한다`(KDS).
- `definition`은 **원문 정의 문장을 그대로** 옮겼다. 원문 줄바꿈 때문에 끝이 잘린 2건(내진율, 인접 대지경계선)은 원문에서 문장 끝(`말한다.`)까지 이어 읽었다.
- `explanation`(쉬운 설명)과 `category`는 직접 작성했다. 분류는 기존 사전에 이미 쓰이는 값만 썼다. 영문 병기가 있으면 설명 끝에 `영문:`으로 적었다.
- `hanja`는 원문에 한자가 병기된 경우(공칭공경 公稱孔經, 분획분자량 分劃分子量)만 채웠다. 원문 표기를 그대로 옮겼다.
- 같은 용어가 여러 기준에 있으면 KDS → KCS → KWCS, 같은 종류 안에서는 최신 개정판을 채택했다.

## 중복·제외 (58건)

띄어쓰기·대소문자·괄호 안 표기를 무시하고, `data/standards-synonyms.js`의 동의어 묶음까지 같은 용어로 보고 대조했다.

| 이유 | 건수 |
|---|---|
| 기존 사전에 있음 | 39 |
| 같은 용어를 다른 기준(KDS 61 15 00)에서 채택 | 8 |
| 기준 안에서만 특정 뜻으로 정의된 일반 단어 | 8 |
| 용어가 아니라 표 항목·설명문 | 3 |
