같은 날 상하수도 기준(`docs/dictionary-update-20260922-kds.md`)에 이어, 설계기준 검색에 새로 넣은 토목 공통 기준 215개 파일을 대상으로 했다. 방법은 상하수도 작업과 같다.

- 각 기준의 **'용어의 정의' 조항(293개)** 에 정의된 용어만 뽑았다.
- 원문은 설계기준 검색 색인과 같은 방법(rhwp 추출 → 화면 줄바꿈을 문단으로 복원 → 머리글·바닥글·쪽 번호 제거)으로 읽었다. 이번 작업 중 짧은 문서의 머리글 형식(`KDS 11 00 00 지반설계기준`, `… KDS 11 60 00 : 2025`)과 머리글 앞뒤 빈 줄을 처리하도록 색인 규칙을 보강해, 쪽 경계에서 끊겼던 정의(정착구, 머신컨트롤, 파동이론분석, 발바퀴, 공사관리 등)를 원문대로 이었다.
- `definition`은 원문 정의 문장을 그대로 옮겼다. 끝에 붙은 원문 각주 번호(예: `…최대유효연직응력1`)만 뗐다. 원문에 같은 정의가 두 번 겹쳐 들어간 엔드이펙터는 첫 문장만 썼다.
- `explanation`(쉬운 설명)과 `category`는 직접 작성했다. 분류는 기존 사전에 이미 쓰이는 값만 썼다. 영문 병기가 있으면 설명 끝에 `영문:`으로 적었다.
